Arquitectura

Un flujo simple y verificable

El cliente conserva la sesión, Flask procesa las solicitudes y SQLite almacena los usuarios.

01

Cliente de consola

Envía solicitudes HTTP y conserva la cookie recibida durante el login.

→
02

API Flask

Valida datos, comprueba credenciales y protege el acceso a las tareas.

→
03

Base SQLite

Guarda usuarios únicos y únicamente el hash de cada contraseña.

API REST

Endpoints disponibles

POST /registro

Crea un usuario y almacena su contraseña de forma segura.

POST /login

Verifica las credenciales e inicia una sesión.

GET /tareas

Muestra el HTML de bienvenida al usuario autenticado.

POST /logout

Elimina la sesión activa y vuelve a proteger el acceso.
